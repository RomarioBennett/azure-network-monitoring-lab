# GitHub evidence checklist

Capture screenshots from your own Azure deployment. Do not fabricate results.

- [ ] Resource group overview
- [ ] VNet address space and subnet
- [ ] NSG TCP/80 rule and source scope
- [ ] VM overview showing private IPs and no VM public IPs
- [ ] NAT Gateway subnet association
- [ ] Nginx service active
- [ ] Successful private TCP/80 test
- [ ] Connection Monitor configuration and baseline
- [ ] Log Analytics discovery query and returned table(s)
- [ ] Analysis query showing actual records
- [ ] Nginx stopped and failed test observation
- [ ] Nginx restarted and successful tests resumed
- [ ] Cost Management summary
